読み誤りを減らす規格

ASD-STE100×Agent Skill

LLMの「それっぽい文章」の癖を、航空業界の統制言語 ASD-STE100（Simplified Technical English）に寄せて抑える仕組みです。

対象：技術文書（手順・不具合報告・リリース等）。目的：誤読リスク低減。
problem
03 / 16
“わかりやすく”は曖昧

制約がないと崩れる

一般的なプロンプトは主観語（例：「わかりやすく」）になりがちで、LLMのばらつきで長文・曖昧表現・条件の誤配置が起きます。

よくある崩れ
長すぎる文／受動・曖昧な助動詞／冗長な修飾
誤読の火種
「いつ・何を・どの確度で」が解釈ブレする
対策は“テスト可能なルール”で文章生成を縛ること。

感覚ではなくルール

53ルールで矯正

AminBlg/SimpleEnglish は、ASD-STE100の考え方を「53の番号付きルール（9セクション）」としてLLM出力に適用するエージェント・スキルです。

文の長さ
1文が長くなり過ぎないよう制限
時制・一貫性
単純な時制に寄せ、判断を固定
一義性
同じ意味を別の言い回しで崩さない
能動態
受動に寄りにくくする
曖昧助動詞
may/might 等を避ける設計
条件の位置
条件文を後ろに回さない
ポイント：規約的な“文章の癖”を構造で抑える。

感性→仕様

“わかりやすさ”の代替

ASD-STE100は、文の長さ・能動態・時制・曖昧助動詞回避・条件位置などをルール化しているため、LLMに従わせやすく出力のばらつきを減らせます。

一般プロンプト
読みやすい（主観）→結果が変動しやすい
STE寄せ
文法・構造（客観）→結果を安定化
用語の併記：主に “誤読（misreading）” を抑えるための writing constraints（文章制約）です。
distinction
08 / 16
認証ではない

保証しない設計

このスキルは ASD-STE100 の“認定（certification）”を保証しません。語彙辞書や厳密判断が絡むため、完全準拠を自動で担保できない可能性があります。

READMEの注意
認証を保証するものではない（免責）
運用への示唆
公式基準との照合＋人レビューが必要
形式的ルールの近づけ方は強力でも、最終責任はプロセス側に残る。
evidence
09 / 16
バラつき対策

曖昧さを固定する

may/might 等を禁止するのは、確度の曖昧さが読者の解釈を揺らすからです。“いつ・何を・どの確度で”を安定化させます。

避ける例
should/would/may/might（曖昧な助動詞）
狙い
行動の解釈を固定（誤読予防）
必要なら
運用設計で別表現・別区分に置換
目的は“不自然さ”ではなく“読み手志向の誤解予防”。（ロボット文体ではなく安全寄せ）

良い文章＝品質プロセス

過信しない運用

このスキルの効果は、STE違反の判定ロジックや辞書ルールの範囲に依存します。厳密監査には、公式規格との照合に加えてテスト・レビュー・更新管理が必要です。

不足しがち
STE違反判定ロジックの全容
不足しがち
“辞書ルール扱い”の詳細
追加で必要
タスクと文書領域の代表性の妥当性
結論：支援ツールとして有力。ただし最終判断は人とプロセスに残す。
enumeration
12 / 16
要点（評価軸）

なぜ効く？

このスキルは「文章の癖」を検証可能な指標に寄せ、実務文書の誤解を減らす方向で設計されています。

i. Evaluable（評価可能）
違反率など指標と回数が提示され、改善を検証しようとしている
ii. Practical（実務性）
エラーメッセージ／手順／報告など、文書種別に合わせる意図
iii. Safety（安全）
曖昧さを抑え、航空整備の“致命的誤読”を防ぎやすい
iv. Technological（技術）
Agent Skills系で導入しやすく、依存が少ない
v. Legal/Regulatory
規格は登録商標で無関係である旨が明記
vi. Communication
長さ・助動詞・条件位置の制御で解釈の再現性が上がる
ただし、認証保証ではなく“近づける”ための支援である点が重要。
closing
13 / 16
結論：支援＋検証

“ルール化”が効く

AminBlg/SimpleEnglish は、ASD-STE100の53ルールでLLMの曖昧な書き癖を抑え、技術文書を読み手志向に寄せる有力なAgent Skillです。

できること
誤読リスクの低減、出力のばらつき抑制、実務文書への適用
できないこと
ASD-STE100の“認証”を保証しない。内容の正確性は別途確保が必要
運用提案：生成→ルール適合度チェック→人レビュー→公式基準照合（重要領域ほど）。
