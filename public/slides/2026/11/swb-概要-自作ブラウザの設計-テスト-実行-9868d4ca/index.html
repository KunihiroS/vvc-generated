swb 概要

Rust自作ブラウザの中核方針、実行・検証手段、未完領域を一枚ずつ整理します。

03 / 17
理解の入口

何が自作？

swbはブラウザの中核（CSS/レイアウト/ペイント、DOM、Web API、JavaScriptエンジン、ページロード、UI）をこのリポジトリで担います。HTTP/TLSやトークナイザ等は汎用ライブラリを活用し、範囲を線引きしています。

境界線

自作 vs 利用

自作（中核）
CSS・レイアウト・ペイント / DOM / Web API / JavaScript / UI / ロード
自前実装で挙動理解・研究を狙う
利用（基盤）
HTTP / TLS / HTMLトークナイズ / 画像デコード / フォント / 2Dラスタ / ウィンドウ制御
一般用途ライブラリで現実に走らせる

05 / 17
まず安全側

JavaScript OFF

JavaScriptはデフォルトOFFです。JSは--js（またはJSボタン、Ctrl+Shift+J）で次のページ読み込みから有効になり、適用にはリロードが必要です。
EVIDENCE
06 / 17
クラッシュ回避

スタック制限

JSにはスタック制限が関係し、ulimit -sで8MiB以上のような設定が必要です。満たさない場合、JSボタンがグレーになり実行を抑制します。

07 / 17
検証の道具

ヘッドレス

ヘッドレスでスクリーンショット取得やレイアウトダンプができます。さらに--js --evalで評価、--benchでパイプライン段階の時間計測も可能です。
ARCHITECTURE
08 / 17
外から動かす

WebSocket制御

リモート制御はWebSocketで行います。--remote-port 0で127.0.0.1上にサーバを起動し、テストやツールからブラウザを駆動する導線があります。
