Desktop Fly, だけど神経

vibecode匂い入力

Desktop Vibe Fly は、FlyWire由来のスパイキング神経回路で3Dの「デスクトップ上のハエ」の行動を決めます。
そのforkで、作業先へ誘導するために “vibecode＝匂い” を追加しました（匂い→目的地探索）。

problem
03 / 16
UIアニメ止まり？

目的地が弱い

通常のデスクトップ常駐は「見た目のアニメ」で終わりやすく、“今向かうべき作業場所”に意味づけできません。
このforkは、神経モデルに意味的な入力をつなぎ直して、探索を行動へ翻訳します。

architecture
04 / 16
脳配線で決める

FlyWire×LIF

元の DesktopFly は 23,210個のニューロン位置をレンダリングし、約1kHzの LIF（リーキー積分発火）でスパイクを計算します。
逃走やステアリングはスクリプトではなく、LC4/LPLC2、DNp01（GF）、DNa01/DNa02などの回路出力で決まります。

looming
カーソル接近 → GFスパイク判定
steering
DNa01 / DNa02 が目的方向へ誘導
metaphor
05 / 16
匂いは比喩

odour＝手掛かり

「匂い（odour）」は実センサではなく、ディスク上のプロジェクトマーカー（例: AGENTS.md や CLAUDE.md 等）をスキャンし、意味的入力として扱います。
そして、その手掛かりを画面の該当ウィンドウ／アイコンへマッピングします（匂い→移動）。

Odour（匂い）: meaning cues / 作業手掛かり
process

ディスク→画面

マーカー群を起点に、エディタ／ターミナル／Finderの行／デスクトップフォルダアイコンのどれが“匂い源”になるかを決めます。

07 / 16
強さが階層化

vibecode量

匂いの強さと到達範囲は vibecodeの量 と 状態（開/閉）で階層化されます。
開いているプロジェクトは強く、閉じたアイコンは弱くなります。

state
open＝強 / closed＝弱
range
vibecode多いほど“届く”半径が広がる
evidence
08 / 16
遠いと段階的に起動

覚醒→飛行

匂いが遠い場合は、即座に移動せず内部状態（人口／興奮度）が十分に高まるまで待ちます。
十分近づく／十分条件が揃うと、飛行（または移動）が開始されます。

far
覚醒が足りず、遅れて反応
near
閾値到達 → GF周辺の発火条件が整う
distinction
09 / 16
逃走は別経路

odour ≠ escape

Escape（逃走）は匂い入力と基本的に独立です。
カーソル接近の looming が GF（ジャイアントファイバー）をスパイクさせるかどうかで決まります。

Escape
looming → GFスパイク → 逃走
Odour
vibecode匂い → 目的地への誘導

10 / 16
移動はDNa

steeringが主役

実際に画面上の移動を担う主体は DNa01 / DNa02 のステアリングニューロンです。
匂いが誘因となり、段階的な内部状態変化を経て、目的地へ向けた制御が走ります。

1
odour入力（意味的手掛かり）
2
覚醒／閾値（人口の増加）
3
DNa01/DNa02 → ステアリング
comparison
11 / 16
上流を壊さない

変更は限定的

forkは「脳・身体・デスクトップセンサ（上流）はそのまま」と明言しており、追加は“匂い入力→方向付け”に限定されています。
そのため、神経モデルの整合性を壊しにくい設計思想になっています。

kept
脳／身体／センサ系（上流）
added
vibecode匂い→目的地誘導の入力層
evidence
12 / 16
仕様は曖昧だらけ

検証課題

READMEからは、vibecodeの検知・重み付け・画面マッピングの 厳密仕様が十分に読み取れません。
実運用では、誤誘導や環境差（複数ディスプレイ等）を想定した検証指標が必要になります。

unclear
エージェント判定、vibecode集計、到達半径の算出
衝突時の解決策も不明
risk
ウィンドウ座標推定／優先順位崩れ／スキャン負荷
迷子・邪魔の可能性
closing
13 / 16
神経×ワークフロー

次の一手

Desktop Vibe Fly は「神経科学っぽい挙動」を娯楽で終えず、作業対象（プロジェクト）へ誘導するインタフェースへ進化し得ます。
ただし成功の鍵は、匂いマッピング（検知・重み・距離・衝突）を明確にし、誤動作を測って改善することです。

目標: “どの匂いが、どの画面要素へ、なぜ到達したか” を説明可能にする（再現性の確保）。
