problem
03 / 16
“動く”だけでは不足
失敗要因は 横断
vLLM（推論ランタイム）をROCmでMI300Xに載せると、FP8/KVキャッシュ/スパース注意/推測復号/カーネル互換性の実装差で、性能以前に品質や安定性が崩れ得ます。
正確性（correction）FP8形式差・MoEルーティング
可用性（OOM回避）HBM容量・KVハイブリッド設計

“形式違い”の罠
FP8は 言語
同じ「FP8」でも、MI300Xは実装セマンティクスがNVIDIAや他世代と違い、取り違えは最大でスケール誤差（因子2）になり得ます。
OCPstandard（一般想定）
FNUZMI300X側の説明
MXFP4MoEルーティング絡み
architecture
05 / 16
容量設計が土台
Weightsは HBM
モデル（304B級）は追加の重み量子化なしでHBMに載せ、KVキャッシュはGPU 20GB + CPU 96GiB（tier）でハイブリッド管理する方針です。
GPU KVfp8_ds_mla
CPU KV長文・同時実行のOOM回避
この設計に同期/フェンス修正が効いた可能性があり、64ストリームバーストでOOMやエンジンエラーを回避したとされています。

優先順位は3段
READMEの主張の核は、性能チューニングより先に「誤差が出る可能性を潰す」ことです。
i. FP8/MXFP4正確性ファースト修正
ii. MoEルーティングパディング・マスク条件
iii. KV同期CPU-KV退避の安全化

08 / 16
Speculativeを成立
DSpark-7 を ROCmへ
推測復号（Speculative decoding）は難所ですが、本構成ではProbabilistic drafting・block rejection・causal verificationを組み合わせて、単一ストリームでの正しい出力前提を扱います。
Probabilistic drafting確率的ドラフティング
Block rejection拒否で誤りを抑制
Causal verification因果検証
さらにGumbelノイズ拒否・復旧ノイズ独立化などのオーバーレイを用いると説明されています。
comparison
09 / 16
NVIDIAレシピは転用不可
互換性が 壁
vLLMの公式レシピが主にNVIDIAやより新しいAMDを想定している場合、MI300XのFP8形式差やMoEルーティング、HIPグラフ/KV同期の実装差でバグや誤差が起き得ます。
NGになり得る要因FP8フォーマット・MoEカーネル
結果スケール誤差（最大因子2）・品質劣化
性能チューニング以前に、取り違えを“修正で潰す”ことが強調されています。
architecture
10 / 16
固定が再現性
vLLM は nightly固定
本番運用では、vLLM ROCm nightlyの選定を固定し、実行イメージやオーバーレイをdigest pinned・SHA256整合性で担保します。
digest pin同一成果の再現性
SHA256検証依存の揺れを抑える
推測性能や正確性に影響するため、運用の基礎として位置づけられています。
distinction
11 / 16
“追加量子化”の意味
追加なし＝ weights不変
READMEの前提は「checkpoint runs as shipped」で、少なくとも重み自体の追加量子化やlayer offloadはしていないことが強調されています。
追加なし（解釈）重みの追加量子化・分割オフロードなし
最適化はあり得るKVキャッシュやカーネル形状（FP8等）
運用上は「weightsではない最適化が何か」を切り分けて理解するのが重要です。
evidence
12 / 16
重要テストと限界
品質合格の 基準
代表的な品質テスト（BFCL subset、tool-calling fixtures）は言及がありますが、実運用の合否指標（許容誤差・再現回数・失敗時挙動）は読み取りづらいとされています。
指標の不足許容誤差・失敗率・長時間安定
観測の必要温度・分散・SLA設計
前提再計測と自環境の品質検証
SLA判断には、tok/sだけでなく監視指標（OOM兆候、キャプチャ失敗など）を含めるのが前提になります。
closing
13 / 16
手順書としての価値
結論： 横断補正
このリポジトリの価値は、FP8/MXFP4の正確性問題と、KVハイブリッド・推測復号・ROCm nightly固定などを“運用可能な形”へ分解して補正している点です。
強い点誤差を先に潰し、固定で再現性
注意点プロンプト/環境依存。導入前に再計測
次の一歩：目標SLA（TTFT許容、同時性、ツール精度）と想定プロンプト長を教えてください。要件に合わせて当てはめを整理できます。
