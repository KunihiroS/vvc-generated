Macの“AI”更新

M6 × M5 Ultra

Mac miniのM6と、Mac StudioのM5 Ultraを発表。計算力とAI処理（AI compute）を強化し、ローカルでの大きい作業を速くする狙いです。

※本デッキは提示文（要約/Points/FAQ/意見）をもとに整理しています。
Problem
03 / 16
速さの理由

CPU/GPUだけでは足りない

AIや動画編集は「計算」だけでなく「データを運ぶ速さ」が効きます。そこでAppleは、メモリ帯域とニューラルエンジンも同時に引き上げる方向性を打ち出しています。

キーワード：Unified Memory / Bandwidth / Neural Engine
Architecture
04 / 16
M6の核

2nm × Dual Neural Engine

M6はApple初の2nmチップで、CPUは12コア構成、GPUも12コアに拡張。さらにDual 16コアNeural Engineで、オンデバイスAIの実行を速める設計です。

計算（CPU/GPU）
CPU 12 / GPU 12（構成拡張）
AI（Neural Engine）
Dual 16（2基でAI処理）
日本語：デュアル（Dual）＝2基。オンデバイス＝Mac本体で実行。
Evidence
05 / 16
M6の“供給”

Unified Memory帯域 170GB/s

M6の統一メモリ帯域は最大170GB/s。データ供給が速いほど、AI推論や編集のような“データ量が多い作業”で有利になりやすい、という考え方です。

メモリ容量
最大32GB
帯域（速さ）
最大170GB/s
狙い
待ち時間を減らし、実行を伸ばす
体感はアプリ実装やモデル要件にも依存します。
Metaphor
06 / 16
“運び”を強化

計算より先に詰まる所

コア数を増やしても、データの移動が遅ければ伸びません。そこでAppleは、Neural Engineの強化だけでなく“帯域”を設計の中心に置いています。

詰まり（ボトルネック）
メモリ帯域 / データ移動遅延
対策
Unified Memory / 接続の高速化
“GPUが速い”＝“全部が速い”ではない、がポイントです。
Architecture
07 / 16
M5 Ultraの核

UltraFusion × クアッドダイ

M5 UltraはUltraFusionによるクアッドダイ構成をM-series SoCで初採用。複数ダイを単一プロセッサのように扱い、デスクトップ級の“計算＋供給”を狙います。

設計
UltraFusionで複数ダイを結合（クアッドダイ）
狙い
単にコア数ではなく“データ移動”も改善
UltraFusion：ダイ間を“1つのSoC”として統合する発想。
Comparison
08 / 16
M5 Ultraの規模

CPU最大36 / GPU最大80

M5 UltraはCPU最大36コア、GPU最大80コア。さらに統一メモリ帯域は最大1.2TB/sとされ、M3 Ultra比の大幅改善が示唆されています。

CPU
最大36コア
GPU
最大80コア
帯域
最大1.2TB/s
TB/sは1秒あたりのデータ転送量の単位。
Evidence
09 / 16
AIは“ローカル”へ

Neural Engine 32 × 大容量

M5 Ultraは32コアNeural EngineでオンデバイスAIを強化。統一メモリ最大512GBで、巨大データをローカルに置いたまま大規模LLMを動かす前提を厚くしています。

AI計算
Neural Engine 32（推論）
データ保持
最大512GB（ローカル前提）
オンデバイスAI＝Mac本体でモデルを実行（FAQの整理に基づく）。
Process
10 / 16
開発者が得する形

フレームワークが横断最適化

AppleはCore AI / Core ML / Metal / Xcodeの連携を通じて、CPU・GPU・Neural Engineを横断して最適化する方向性を示しています。ユーザーが細かく“調整”しなくても性能が出やすい設計です。

ツール
Core AI / Core ML / Metal / Xcode
効果
AI実行の高速化をソフト側で引き出す
最終的な伸びは、実装（アプリ）側の最適化次第です。
Distinction
11 / 16
用途の分担

M6は日常〜開発 / M5 Ultraはプロ

一般にM6は日常・学生・開発者・AIホビイストにもバランス良く、M5 Ultraはプロ用途や大規模AIワークロード向け。製品レイヤで役割分担が説明されています。

M6（狙い）
日常〜開発、ローカルAIの待ち時間短縮
M5 Ultra（狙い）
3D/VFX/科学解析/大規模AIなど高負荷
“何をどこまでローカルで回すか”が選び方の軸になります。
Distinction
12 / 16
買い替えの注意

最大値は“条件つき”

リリースの主張は内部テストや選定ベンチマークに基づく表現が中心で、実ユーザー体験はアプリ実装・モデルサイズ/量子化・OS/フレームワーク・電力/発熱にも左右されます。最大性能をそのまま自分の用途に直結させないのが安全です。

変動要因
アプリ最適化 / モデル要件
条件
最大値・特定ベンチ前提
追加情報
第三者レビュー/実測/利用シナリオ
“速くなる可能性”は高いが、“確定”はできない、という立場です。
Closing
13 / 16
結論

オンデバイスAIを“現実”へ

M6は2nmとDual Neural EngineでローカルAIを加速し、M5 UltraはUltraFusionクアッドダイと最大帯域で“移動”を強化。計算資源とデータ供給をセットで上げる発表で、デバイス上でAIを回す現実味が増しています。

強み
計算×メモリ帯域×Neural Engine
