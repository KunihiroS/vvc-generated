Core
04 / 18
核心
反例は分類
「論理形式としての存在反例」と「数学での反例（崩しとしての重み）」は同じではない。反例かどうかは、形式だけでなく文脈で決まります。
Basics
05 / 18
前提
量化
数学の命題は forall（全称） と exists（存在） で形が変わり、否定の見え方も変わります。反例は「否定できる対象」以上の意味を持つことが多いです（例としての重み）。
Evidence
06 / 18
ズレの例
Vinogradov
Vinogradovの「十分大きい整数は3つの素数の和である」は、論理的に見ると否定側に“存在”が現れます。しかし数学ではそれは通常、反例ではなく定理として扱われます。
論理形式
否定は“存在の形”を要求し得る
形式的には反例っぽい
数学の扱い
しかし実際は「定理」として定着
文脈・期待値が違う
Evidence
07 / 18
同じ主張でも
呼び名変化
Banach–Mazur compactumの直径の話のように、同じ論理構造でも「定理／例／反例」と呼ばれる側面が変わることがある、と著者は指摘します。
Skolem化
量化の形を“レシピ化”し得る
全称↔存在の見え方が変わる
量化の焦点
どこに量化の中心があるかで印象が変化
例にも反例にも見える場合

08 / 18
言い換え
探索モード
LLMの強みは「全称否定（反例）を見つける能力」そのものより、知識と探索の速さで“特定の形の例（および証明）”を見つけるプロセスにある可能性が高いです。

09 / 18
勝敗のズレ
反例 vs 例
もし単純に「存在文が得意」だけなら、成果は“反例”の洪水のように増えるはず。しかし現状はそうではない、という観測が前提にあります。
単純仮説
存在文が得意 → 反例が大量に出る
著者の見立て
例探索の得意さ → 特定パターンで勝つ

見え方
既存路線
専門家の反応として「驚いたが、見直すと本質的に独創というより既存の路線にヒントが少し乗っただけかもしれない」という趣旨が紹介されます。LLMの勝ちが“探索の寄せ方”由来の可能性を補強します。

結論（要約）
探索の適応
LLMの強みは「反例探索そのもの」より、知識＋探索速度に支えられた“特定モードの例（と証明）探索”。人間的な枝刈りが本質の問題ではギャップが残り得ます。
