ゲーム仲間を“同時進行”へ

Varkos（ヴァルコス）

会話するAI（LLM）を超え、ゲーム世界の状態を参照しながら低遅延で行動する“ゲーム仲間”を目指すプロジェクト。

キーワード：World state / 低遅延 / Persistent plans / World grounding
problem
03 / 16

会話はできる、でも行動が不安

ギャップ問題

従来のLLM NPCは“役になりきって話す”のは得意でも、“複雑な指示を確実に実行”し“遅延を抑える”のが難しい。

得意（会話）Talk
口調・人格っぽさを保った応答が作りやすい。
苦手（実行）Act
待ち時間が増える／“今の世界”とズレた挙動になりやすい。
architecture
04 / 16

音声から行動へ、低遅延パイプライン

設計の骨格

音声入力→低遅延の解釈→行動計画→音声応答を、可能な限りローカルで回し、世界状態に基づいて動く。

ASR / VAD / Turn音声処理
常時オン前提で、早期ターン判定を最適化する。
ALE 推定行動解析
「Action Latent Encoder」のようなハイブリッド推定で解析。
TTS＋局所LLM応答生成
ローカル微調整LLMで応答・感情付与、グラウンディングで幻覚を抑制。
metaphor
05 / 16

“言葉”でなく“台本”ではなく“計画”で動く

永続的計画

複雑な指示を会話のやり取りで完結させず、persistent plansとして分解し、条件イベントで次へ進む。

例 i行動列
矢を撃つ→合図を待つ→アイテムを拾う→持ってくる。
効果 ii体験
途中を“都度デモ切替”する必要が減り、自律的に続く。
evidence
06 / 16

遅延と“待ち時間”が没入を壊す

“同時進行”狙い

VRではメニュー操作や待ち時間が致命的になり得るため、低遅延の音声・応答・解析で発話と行動を近づける。

設計 iVR耐性
遅い応答はプレイヤー体験を分断する前提で、手前を速くする。
狙い ii存在感
プレイヤーが一人でない感覚を、反応速度と挙動で作る。
distinction
07 / 16

世界参照＝ワールドエージェンシー

世界で裏取り

“ワールドエージェンシー（世界を理解し行動へ反映する力）”を強くし、会話でそれっぽく言うより状態検証で動かす。

用語 iWorld agency
ゲーム世界を理解し、行動に落とせる力。
方針 iiGrounding
アイテム探索を“会話回答”ではなく“実在状態”へ寄せる。
狙い iii信頼性
LLMの幻覚が起きやすい領域を抑える。
process
08 / 16

人格は“別経路”に分離して破綻を減らす

時間軸を分ける

人格進化はリアルタイム経路から分離し、一部はクラウドLLMに依存しつつ、日常的な反応はローカルで成立させる方針。

リアルタイム（短）Fast lane
遅延ボトルネックを避け、即応の質を守る。
進化（長）Slow change
共有体験の証拠から徐々に個性が変わる。
enumeration
09 / 16

Void modeで“世界の有無”を設計する

ゲーム後は切替

ゲーム終了後は“void mode（無世界状態）”に入り、人格進化に応じて反応が変化する。移植性の橋渡しにもなる。

iIn-world
世界JSON等の参照で、行動計画が現実に接続される。
iiVoid mode
見聞きできず状態参照が薄れ、キャラクター性が変わる。
comparison

“会話中心”から

従来 iLLM NPC

Varkos iiAction AI

良い点・技術的強み（体験を守る）

実用×技術×戦略

VRの負担を減らす設計、ボトルネック特定の音声・推定、そして“全部クラウド化しない”現実的戦略が噛み合う。

Practical実用性
待ち時間やメニュー操作の負担を抑える。
Technological技術

Strategic戦略
速い処理はローカル、遅い人格進化は別経路。

制約とリスク：期待値の管理が要る

失敗点も明示

長期会話の一貫性、ゲーム別適応（ALE側の調整）、クラウドでも遅延が解決しきれない可能性が課題として挙げられている。

Reliability長期
スレッド保持が弱く、混乱して見える可能性。
Adaptationゲーム別
ALEがゲームごとに別バージョン必要になり得る。
Latencyクラウド
クラウドLLMでも遅延が課題として残り得る。

13 / 16

“AIが賢いか”より“遊べるか”を設計

次の一手は検証

Varkosは、行動計画・低遅延・世界グラウンディングで“コンパニオン体験”を組み立てる。今後は一般化と長期一貫性の検証が鍵。

Takeaway i要点
会話を目的化せず、世界状態に基づく行動として成立させる。
Takeaway ii次
ゲーム横断・長期会話・安全性の追加情報で期待値を調整する。
