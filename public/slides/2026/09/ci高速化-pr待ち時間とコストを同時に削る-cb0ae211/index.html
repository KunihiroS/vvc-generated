06 / 17
土台を速くする

移行×コンパイラ刷新

GitHub Actionsから第三者ランナーへ移行し、CPU・ストレージ・キャッシュ基盤を改善。結果としてジョブ全体が平均34%高速化し、tscチェックは一部で52%短縮とされています。
Move
Actions → 3rd-party runner
Gain
平均 +34% faster
tsc
一部 -52%（短縮）
さらにTypeScriptコンパイラをtsgoへ切替し、週次中央値でtscを73%削減（型検査ボトルネックを外す）。
Evidence
07 / 17
型依存リントを撤去

リントをASTへ

既存のカスタムルールは型グラフ構築を伴い、メモリ集約でCIジョブを圧迫。ASTベースの静的検出へ改め、TypeScriptをESLintから排除しました。
Replace
型グラフ → AST検出
Result
APIリント -68%／全体 -55%
実行時間だけでなく、資源逼迫による遅延（待ち）も減らし、CIコストに直結。

08 / 17
待ちを直撃で削る

checkout / 検知を最適化

変更検知やパス判定などのゲートが遅れると、後続のテストシャーディング全体が待ちます。そこでフルcheckoutを減らし、fetch深度を制限、必要ないジョブではcheckout自体を削除しました。
Gate
差分検知・パス判定
Cut
不要checkoutを削除
Network
ハング対策（リトライ付き）
変化検知：中央値 26秒→8秒、p90 31秒→12秒。
Process
09 / 17
“シャード万能”は誤解

Vitestは限界あり

Vitestはファイル単位で仕事を割り当てるため、大きすぎるテストファイルがあると最遅シャードが支配します。そこで大型ファイルを分割し、シャード数も調整しました。
Cause
偏り（大きいテストファイル）
Action
分割 + シャード数を 8 へ
初期ベンチで約19%高速・19%安く、最遅シャードも短縮。
Architecture
10 / 17
隔離コストを削る

isolate: false で固定費削減

通常のVitest隔離（ファイルごとの再構築）がコストになっていたため、適切なファイルだけisolate: falseのオプトインプロジェクトを導入。最大の改善として月次で約17%節約を得たとされています。
Default
各ファイルで再構築
Opt-in
共有状態が成立する範囲だけ
Impact
月次 約17% 節約
fake timers等、うまく分離できないケースは隔離プロジェクト側に残した。
Distinction
11 / 17
“速さ”の種類を分ける

平均短縮より待ち短縮

改善は「テストが早くなる」だけでなく、ゲート（変更検知/checkout）やセットアップ固定費を削ってクリティカルパス上の“待ち”を縮める設計です。
CPU/Tool
ランナー移行、tsgo、リント刷新
Gate/Setup
checkout削減、fetch深度制限、反復セットアップ削減
Test
shardingの偏り解消、隔離オプトイン
Principle
セットアップ軽量化がシャーディング増加を可能に
Risks
12 / 17
速さと品質の両立

最適化には検証が必要

特にisolate: falseは性能面で効く一方、独立性が崩れると将来のバグ検出率低下や再現性のない失敗につながる可能性があります。運用では、フレーク率や検出漏れなどの品質指標を併走監視するのが重要です。
Risk
テスト独立性の崩れ
Mitigation
オプトイン範囲限定、例外保持、teardown追加
外部ランナー依存やネットワーク条件変更で効果が揺れるため、性能/品質の継続監視と再評価が不可欠。

Sources & 関連

本スライドは、ユーザー提示の本文要約に基づいています。追加調査のための一般的な観点（変更に応じた実行削減など）に近い参照先を挙げます。
CI / Sharding / Vitest（一般）
Vitestのshardingはファイル単位での割当になりがちで、偏り（大きいテストファイル）が最遅シャードを支配する、という理解の裏取りに。
GitHub Actions checkout & fetch最適化（一般）
checkoutやfetchの深度・不要実行の削除がクリティカルパス短縮に効く、という観点の一般知識。
差分実行・最小変更領域の検証（一般）
CloudBees Smart Testsのような「変更に応じて実行を絞る」アプローチは、差分検知の徹底と整合しやすい。
Test isolation（一般）
isolate: falseの安全性はケース依存。フレーク率・検出漏れなどの品質指標を併走監視する、という考え方の裏取りに。
