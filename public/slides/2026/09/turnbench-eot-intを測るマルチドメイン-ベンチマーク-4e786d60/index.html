TurnBench
02 / 19
会話の“転換点”を測る
EOT / INT Detection
TurnBenchは、話者交代のタイミング（End-of-turn: EOT）と割り込み（Interruption: INT）を、精度・誤検出・遅延で評価するベンチマークです。
problem
03 / 19
誤ると会話が壊れる
実運用の痛点
音声対話システムは、EOT/INTを誤ると不自然なタイミングで応答・相槌が出たり、会話が途切れたりします。
誤検出（体験劣化）
相手の発話権を奪う／早すぎる応答
見逃し／遅延
言い直し・応答の遅れ・会話の停滞
architecture
04 / 19
イベントを“検出”にする
EOT と INT
TurnBenchは二者間デュアルチャンネル会話で、EOT（話し終わり）とINT（相手が話している途中の奪取）を人手注釈し、モデルの検出能力を測ります。
End-of-turn (EOT)
相手が話し始められる状態
日本語：話者交代の終了点
Interruption (INT)
相手の発話中に発話権を奪う
日本語：割り込み（奪取）
enumeration
05 / 19
3軸で勝負する
Recall / FPR / Latency
モデルは各会話に対してEOT/INTの「検出時刻リスト」を出し、見逃し・誤検出・遅れを同時に評価します。
Recall
見逃さず検出する割合
FPR
存在しないイベントの誤検出率
Latency
イベント後に検出するまでの遅れ（p50, ms）
distinction
06 / 19
FPRに予算がある
資格条件
TurnBenchでは、FPRが0.15を超えると運用上の条件として資格外になる設計が示されています。
なぜ重要
誤検出は発話権を奪い、体験を壊すため
読み方
“高Recallだけ”は不十分（FPR監視が必須）
evidence
07 / 19
EOT と INT の性格が違う
傾向の分岐
提示結果では、EOTのRecallは会話タイプに依存しにくい一方、INTの誤検出（false positive）はカジュアル会話で増えやすいと述べられています。
EOT
会話タイプ依存が小さい傾向
INT
カジュアルでFPRが上がりやすい
日本語：割り込み“らしさ”に引っ張られる
metaphor
08 / 19
“似ている音”が罠
Backchannel 誤認
INTのfalse positiveは、カジュアル会話に多い相槌（backchannels）が“割り込みのように聞こえる”ことが原因だと説明されています。
相槌 (backchannel)
短く入りやすい
日本語：割り込みと音響形状が近い
モデルの誤認リスク
発話奪取を音響的に取り違える
日本語：INT検出の過敏さ
comparison
09 / 19
速さ vs 信頼性
音響・意味のトレードオフ
音響ベースは沈黙に過敏でRecallは高いがFPRが増えやすく、セマンティックベースは選択性がある反面、遅くなりがちです。
音響的検出
Recall ↑ / FPR ↑（沈黙で過剰反応）
セマンティック検出
FPR ↓ / Latency ↑（遅延しやすい）
distinction
10 / 19
全部同時は未到達
同時最適化の難しさ
提示文では「速さ・高Recall・低FPRをすべて満たすモデルはまだ存在しない」と結論づけています。
理想
速い（Latency小）
理想
見逃さない（Recall大）
理想
誤報しない（FPR小）
evidence
11 / 19
強い候補：VAP
VAP が先行
ランキング要旨では、VAP（Voice Activity Projection）がEOTとINTの両方で強い傾向が示されています。
EOTでの強さ
検出性能が相対的に高い
INTでの強さ
割り込み側でも競争力
※ただし、上位でもFPR/Latencyのバランスが鍵になります。

注釈者
3名
一致度

未来情報は使わない
Causal 提出要件
提出は因果的（causal）で、時刻tの予測はt以前に観測された音声だけに依存する必要があります。
防ぐこと
未来音声の利用（情報リーク）
得られる価値
実運用に近い比較と再現性
evidence
14 / 19
早めに備える人間
151ms前開始
人間はターン転換を「ターン終了の151ms前」から始めるという観測があり、モデルにはより低遅延のリアルタイム性が求められていることが分かります。
観測
EOTの151ms前から準備開始
含意
Latencyは小さいほど有利
closing
15 / 19
読むべき結論
見方の要点
TurnBenchは「Recallだけでなく、FPR予算とLatencyを同時に満たす検出器」を促す設計であり、特にINTは会話タイプ（カジュアル）で誤検出が増えやすい点が重要です。
EOT
Recallは相対的に安定
INT
backchannel誤認でFPR増
総合
因果性 + 3軸評価が鍵
