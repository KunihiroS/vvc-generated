巨大 safetensors を、GCSから起動時に約17.5GB級ストリーミングし、/dev/shmへ展開して推論を早める。

2. 起動展開
/dev/shmへ RAM-backed（高速領域）
3. 推論開始
vLLM APIサーバ起動 Inference server（推論提供）
狙い：ゼロからの起動でも“待ち時間”を小さくする。

forkと最適化抑制

vLLMワーカーの起動に `VLLM_WORKER_MULTIPROC_METHOD=fork` を使い、再import等のオーバーヘッドを避ける。

省略する工程

`TORCH_COMPILE_DISABLE=1` compile / graph capture（起動時最適化）
