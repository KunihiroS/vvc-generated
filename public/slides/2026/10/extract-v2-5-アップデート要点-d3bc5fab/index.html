Extract v2.5
02 / 16
ドキュメント抽出アップデート
要点まとめ v2.5
Extract v2.5は、スキーマに沿って情報を取り出す抽出エージェントを強化しつつ、1ページ価格は据え置くことを主張するアップデートです。
Problem
03 / 16
抽出は“失敗パターン”が多い
現場の詰まり
複雑なレイアウト、複数ページにまたがる情報、スキャン帳票のノイズ、推論途中停止、検証が難しい――これらが抽出失敗の典型です。
失敗
長いリスト / 明細の取りこぼし
失敗
ページ跨ぎの未完結（途中で切れる）
失敗
スキャン帳票の注記・手書き混在
失敗
根拠（citations）が弱くレビューが重い
Metaphor
04 / 16
“当てる”より“探し当てる”
スキーマ抽出
Extractは、Pydantic等のスキーマ（項目の形）を与えて「何を探すか」を明示し、抽出結果を根拠付きで返します。
Input
PDF / スキャン / 帳票
Schema（形式）
金額・住所・条件・明細行…
Output
値 + citations（根拠・位置）
Goal
レビュー工数を減らす（監査しやすく）
核心
05 / 16
Value F1 と Grounding
同時強化
Extract v2.5は、精度（Value F1）と根拠提示（グラウンディング）を強化しながら、最終的にコスト効率を改善することが中心メッセージです。
主張
「高精度＝高コスト」を弱める
主張
最上位だけでなく中位tierも改善
根拠
ExtractBenchで全tierに向上
条件
1ページあたり価格は据え置き（no increase）
Evidence
06 / 16
全tierで Value F1 向上
コスト効率が上がる
ExtractBenchでは全tierでValue F1が改善（例：Cost Effective 87.1→93.9、Agentic 89.8→95.8、Agentic Plus 95.1→96.4）と報告されています。
Cost Effective
87.1 → 93.9
Agentic
89.8 → 95.8
Agentic Plus
95.1 → 96.4
意味（要点）
“同じ価格帯で”価値が増える
仕組み
07 / 16
Structural Reasoning
努力量を動的に最適化
Structural Reasoning（構造推論）で文書種類・レイアウト・情報密度に応じて処理量（推論の深さ）を調整し、単純文書は低遅延、複雑文書は精度を取りに行く設計です。
簡単
低レイテンシを維持
複雑
より深い推論・検証
対象
長い明細 / ページ跨ぎ
狙い
無駄な推論コストを抑える
Distinction
08 / 16
Advanced Citations 拡張
根拠の精度を上げる
Advanced CitationsがAgenticに拡張され、難しい項目でもバウンディングボックス等の根拠提示をより正確にできるようになったとされています。
Beforeの課題
根拠が弱くレビュー負担が増える
Afterの狙い
citations（根拠・位置）を強化
対象
注記/分離/曖昧な項目
効果
監査・確認のやり直しを減らす
Evidence
09 / 16

“根拠スコア”が伸びる
グラウンディングスコアはAgenticで46.8→80.6、Agentic Plusで46.4→82.2へ上昇したと記載されています。
Agentic
46.8 → 80.6

46.4 → 82.2
意味（要点）
根拠のレビュー可能性が上がる
用語
grounding（根拠付け）

帳票

効果
人的手直し・監査コストの削減

スキーマ規模
最大3,200フィールド

スプレッドシート（セル直指定）
課題

FAQ / Risk
12 / 16
導入前に確認したいこと
懐疑的チェック
v2.5は魅力的ですが、ベンチマーク偏り・例外率・実運用の再実行/レビュー工数・価格据え置きの条件などは別途検証が必要です。
1
ExtractBenchの文書内訳・サンプル数
2
実運用のレイテンシ/例外率（human-in-the-loop前提）
3
「no increase in per-page pricing」の適用条件
参考：citations/ confidence scores改善があっても、極端に崩れたスキャンでは人の確認が必要な可能性は残ります。 （自動化 100% は保証されない）
Closing
13 / 16
結論
“抽出品質”＋“根拠の実用性”
Extract v2.5は、精度だけでなくコスト効率と根拠提示（grounding/citations）まで踏み込み、現場でのレビュー負担を下げる方向性を示したアップデートです。
強み
中位tierでもValue F1が改善
強み
グラウンディングの上昇が大きい
確認
対象文書でPoCし、例外率と総コストを測る
用語（訳）
tier（グレード） / grounding（根拠付け） / citations（引用・根拠）
